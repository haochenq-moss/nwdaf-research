External NWDAF-like Security Analytics Prototype

Detection to verified response

A two-machine workflow connecting the Ubuntu free5GC testbed to GPU-side analytics, policy-bounded workflows, an authenticated response agent, and evidence-backed verification.

Boundary: this is a research prototype aligned with NWDAF concepts. It is not a claim of full 3GPP NWDAF compliance.
01 · Ubuntu

Testbed telemetry

free5GC, free-ran-ue, Linux/process, SBI, PFCP, eBPF where available, and UE service probes.

02 · DCCF

Normalize & correlate

Run IDs, source identity, timestamps, NF context, and complete-run windows.

03 · AnLF / MTLF

Infer & manage models

Random Forest baseline, optional CUDA MLP/GRU, model artifacts, seeds, and provenance.

04 · PDP / SecIR

Gate the action

Confidence, target, duration, evidence, preconditions, postconditions, rollback.

05 · Adapter

Execute bounded action

Authenticated Ubuntu response-agent or controlled Mock NF; no arbitrary shell commands.

06 · ADRF / VFL

Persist & report

SQLite analytics/workflow records, audit JSONL, lifecycle reports, optional callback.

07 · Verify

Check state

UE reachability, qdisc restoration, latency/loss/throughput evidence, escalation on failure.

Control path

Ubuntu evidence → reverse SSH / batch archive → GPU inference → policy decision
→ SecIR typed workflow → authenticated response-agent → ADRF/VFL audit
→ measured postcondition → rollback or operator escalation
implemented/measured prototype pathfuture infrastructure extension

Implemented modules

DCCF

Collects run streams and creates normalized correlated windows.

MFAF

Registers and activates model artifacts with manifest provenance.

ADRF

Persists analytics and workflow evidence in SQLite.

SecIR

Compiles approved decisions into typed, rollback-aware steps.

VFL / NemoIR

Creates operational reports and non-executing evidence summaries.

Response agent

Supports alerting and bounded tc rate limiting with automatic fq_codel restoration.

Explicit future boundaries

Kubernetes / OVS enforcement

Read-only observers exist; quarantine and flow mutation are not enabled.

NF replacement / UPF failover

No clean NF replacement or session-preserving failover is claimed.

OAM/OSS/BOSS integration

Prototype payload/callback only; no external operator platform.
